# CajApp Updates

Canal de distribución de **CajApp Veloz**. Este repositorio sólo contiene la APK publicada y `version.json`, que la app consulta para detectar actualizaciones.

- Descarga directa: [CajApp-latest.apk](https://github.com/servixam-max/CajApp-updates/releases/latest/download/CajApp-latest.apk)
- El código fuente no está aquí.

`version.json` se regenera automáticamente en cada release desde el repositorio principal.
